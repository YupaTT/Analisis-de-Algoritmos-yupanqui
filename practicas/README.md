# Prácticas

Todas las prácticas de Análisis de Algoritmos se guardan aquí, cada una en su propia carpeta. Para correr el código, ejecuta `go run .` desde esta carpeta y elige una opción del menú.

- [`c3/`](c3/): búsqueda binaria a mano.
- [`c4/`](c4/README.md): búsqueda lineal contra binaria, medida, y si conviene ordenar primero en el H1.
- [`c5/`](c5/README.md): torneo de ordenamientos (Inserción, MergeSort y QuickSort).
- [`c6/`](c6/eleccion.md): elección argumentada del algoritmo de ordenamiento para el H1.
